# 高德用法

必须用 **Web 服务** Key，不要用 JS API Key。官方 JS API 不能用 Web 服务钥匙。

## Key 放哪里

按这个顺序读：

1. 环境变量 `AMAP_MAPS_API_KEY`
2. `--env-file`
3. 当前项目 `secrets/amap.env`
4. 当前项目 `amap.env`

不要把 Key 写进 Git、Word、聊天记录。地图 HTML 默认不内嵌 Key；附近搜索会读 `?key=`、`localStorage.AMAP_MAPS_API_KEY` 或同目录 `amap-key.js`。

## 用到的接口

- `/v3/place/text`：按城市和关键词搜店
- `/v3/place/around`：点店后搜附近 3 公里小区、学校、商场/商圈；也可临时搜小学、地铁站
- `/v3/config/district`：城市区划和轮廓

坐标按 GCJ-02，和高德瓦片一致。`extensions=all` 能拿到电话、营业时间、评分、出入口、照片。

## 点店后的 3 公里

点击一家竞品后，地图必须：

1. 在侧边显示门店基本信息（名称、地址、电话、时间、评分、商圈、高德/点评/百度）
2. 按所选半径画虚线范围圈，默认 3 公里；可选 100 米、500 米、1 公里，或自己填米数
3. 用名称图钉标出附近小区、学校、商场/商圈，不画它们的范围小圈。学校可筛幼儿园/小学/初中/高中/其他；可在地图上自选点
4. 列出名称、距离、地址、类型；小区附房价检索链接

过滤口径：

- 小区：住宅区 `1203*`，去掉写字楼、商务楼
- 学校：小学 `141203`、中学 `141202`、幼儿园 `141204`，去掉培训机构、托管
- 商场：购物中心 `060101`、普通商场 `060102`；商圈用热点地名 `190700`

## 做不到的事，不要编

高德 Web 服务 **没有** 地籍红线、小区围墙多边形、挂牌均价。

不要给小区、学校、商场画示意小圈，只标名称。房价写「未查到挂牌均价」，给贝壳 / 安居客 / 百度检索。不要编造单价。

## 配额与打开方式

`file://` 打开地图时，附近搜索可能被浏览器拦住。失败就用本地 HTTP：

```bash
python3 -m http.server 8765 --directory "<输出目录>"
```

然后打开对应 HTML。
