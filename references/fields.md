# 竞品字段与口径

用户没改字段时，沿用昆山在营业搜集这套。只收在营。没查到写「未查到」，黄底可改，不编造。

## 默认保留

- 门店名、品牌、地址、区域、电话、营业时间
- 高德评分（只说明好不好找，不当教学质量）
- 高德地点页、大众点评检索、百度检索
- 核心 / 相邻，P1 / P2 / P3

## 第一层，写报告必须有

| 字段 | 填法 |
| 还在营业 | 在营 / 停业 / 待核。默认只出在营 |
| 公司全称 | 工商登记名 |
| 直营或加盟 | 直营 / 加盟 / 未知 |
| 招生年龄段 | 写成 6-8 / 9-12 / 初中 |
| 课程方向 | 按行业改，少儿科创默认：编程 / 机器人 / 乐高 / 创客 / AI / 3D打印 |
| 是否真AI课 | 有官网或课程页原话才写；口头提 AI 不算 |
| 试听怎么收费 | 价格、时长、能否抵学费 |
| 正课大概价格 | 查不到写未查到 |
| 班型和班额 | 查不到写未查到 |
| 点评星级和条数 | 少于 10 条不当口碑结论 |
| 可借鉴点 / 差异化机会 | 一句能执行的话 |
| 证据链接和日期 | 每条关键事实都能点回去 |

## 默认先不做

店面形态、动手作品、3D打印、威胁等级、第三层信用代码/教室面积，除非用户明确要。

## 优先级

- P1：同业品牌或课程最接近，写单店卡
- P2：其余核心店，写简表
- P3：学科辅导、学习机等相邻入口，只看会不会抢走家长

脚本会按店名粗分，交付前要人工扫一遍名单。
